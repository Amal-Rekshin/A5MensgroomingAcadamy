# 💈 A5 Men's Grooming Academy

A modern and responsive website developed for **A5 Men's Grooming Academy**, designed to showcase the academy, grooming courses, services, gallery, and other important information through a clean and user-friendly interface.

The application is built using **React.js and Vite**, providing a fast, responsive, and modern web experience.

## 🌐 Live Demo

🚀 **Live Website:**
https://a5-mensgrooming-acadamy.vercel.app/

## 📌 About the Project

**A5 Men's Grooming Academy** is a professional grooming academy website created to establish a strong online presence for the academy.

The website allows visitors to explore information about the academy, grooming and hair styling programs, services, gallery content, and other relevant details through a responsive interface optimized for different screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Amal-Rekshin/A5MensgroomingAcadamy.git
```

### 2. Navigate to the Project

```bash
cd A5MensgroomingAcadamy
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The development server will start using Vite.

Open the local URL displayed in the terminal, usually:

```text
http://localhost:5173
```

## 📦 Production Build

Create an optimized production build using:

```bash
npm run build
```

The generated production files will be available inside the:

```text
dist/
```

directory.

To preview the production build locally:

```bash
npm run preview
```
